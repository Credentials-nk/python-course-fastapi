# Python Course - FastAPI

Curso de Python y FastAPI organizado por secciones progresivas. Cada sección extiende el proyecto sobre la anterior, reflejado en ramas de Git.

## Stack

- Python 3.13.7 (pyenv)
- uv (package manager)
- FastAPI + Uvicorn

## Secciones

1. Fundamentos de Python
2. Introducción a FastAPI y primeros pasos
3. Tipado, validaciones y Pydantic
4. Validación de parámetros y queries
5. Bases de datos relacionales con SQLAlchemy
6. Arquitectura y modularización
7. Dependencias, seguridad y JWT
8. Funciones síncronas y asíncronas
9. Manejo de archivos
10. Proyecto final

## Setup
```bash
pyenv install 3.13.7
uv sync
```
